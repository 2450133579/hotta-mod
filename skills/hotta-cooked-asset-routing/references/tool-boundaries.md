# 工具与文件格式边界

| 工具 | 可依赖的用途 | 限制与转向 |
|---|---|---|
| repak | Pak 清单、提取与信息 | 不支持包版本时换已适配路线，不把损坏输出当资源 |
| FModel | 浏览、索引与引用发现 | 索引不全时换工具，不反复配置却无新证据 |
| UModel/UE Viewer | 对象 dump、分析副本、模型/贴图导出 | save 不是 MIC 可重定位的证明 |
| CUE4Parse 系工具 | 解析支持的对象和依赖 | 映射文件、解压库、客户端版本需匹配 |
| UAssetGUI/UAssetAPI | 对支持的完整资源结构化读写 | 必须能解析所需导出/属性且往返可靠 |
| UE4.26 commandlet | 作者资源、导入、蓝图、动画和 Cook | 检查具体资源输入，不用退出码代替语义 |
| UnrealPak/HT | 已适配路线的封包处理 | 不负责修复内部文件头、骨骼或 shader |
| 自制检查脚本 | 检查其已知格式和条件 | 不将未知格式或缺证据判为通过 |
| 已适配 UE4SS + 进程内原生模块 | 读取外部 VMD、运行时重定向、界面和本机音频 | 不提供未知 cooked 格式的解码保证，也不等于所有客户端可用 |

## 完整文件组

按实际资源收集 uasset 与必要的 uexp、ubulk、uptnl，名称、引用和字节来源一致。不要把一套头与另一版 sidecar 拼在一起。

标准包魔数和文件完整只能使其成为解析候选，不证明工具支持或游戏有效。导出的模型、图片、JSON 是分析/作者输入。

## 原生与自制格式

原生 unversioned 容器可能有游戏专属编码。显式版本的自制 UE 资源与其不同，选对应读取方式。已验证的原生头修复只用于匹配输入，不在自制资源上盲套。

包外层压缩或 HT 包装不修复 uasset 内部结构。加载卡住时需要最小对照、真实原字节和分阶段结果，不能凭停在某百分比直接归因运行 Tick。

## 参数与索引

保留真实参数拼写、类型、ParameterInfo、Association、Index 及需要的 ExpressionGUID。调用返回 false、参数未写入或 Cook 后结构不同应停止。

二进制补丁只在布局明确、旧值与周围字节前置检查成立时使用。固定偏移、资源尺寸或某个骨数不属于通用格式保证。

CLI 参数按实际版本核对。文档包没有提供这些工具或凭据，接手者需在自己的环境中配置。

## 运行时 API 与 Lua ABI 的边界

2026-10-12 的 UE4SS v3.0.1 案例中，UFUNCTION 返回的组件数组是普通 Lua 表；反射数组属性则可提供 TArray:ForEach，元素还可能需要 :get() 解包。先检查返回类型，不统一假设为一种容器。

同一版本的嵌套 FTransform 表传参出现递归读取错误，导致零缩放和后续参数错位。使用平面的 FVector/FRotator 接口分别写入位置、旋转、缩放，并回读关键值；不能凭 Lua 表内容正确就认定引擎收到相同数据。

原生桥接核对真实宿主二进制及 Lua ABI，禁止混用第二套 Lua 核心的 lua_State。扫描歧义需由实际函数调用及框架回读验证解决，不能猜构造地址或跳过验证。完整制作路线见制作总入口的运行时 VMD 参考。

# 资源、材质和外观诊断

## 先分类

| 表现 | 优先核对 |
|---|---|
| 原外观不变 | 安装/挂载、目标路径、使用者与阶数、是否被更高优先级覆盖 |
| 新资源存在但无效果 | 是否有从实际 Mesh/MIC 出发的可达引用 |
| 灰格或默认材质 | 父对象、依赖、shader map、资源身份和参数绑定 |
| 部分区域没有效果 | 目标面的材质槽与相邻槽归属 |
| 转模后黑三角或白线 | 绕序、自定义法线、平滑组与完整切线 |
| donor 贴图错位 | UV、遮罩、纹理密度及采样通道 |
| 白天正常、夜间平淡 | 夜间时间驱动、ramp、overlay、mask 与高光 |
| Cook/回读正常但实机异常 | 实际运行的资源链、格式、动画绑定和后处理 |

## 完整可见链

追踪实际面 → Mesh section/材质槽 → MIC → 父对象及类型 → 静态开关 → 参数与贴图 → 原生或打包依赖。

同时检查 UV0、第二 UV/EXTRAUV0、顶点色、颜色/法线/M/ID/LightMap/丝袜遮罩、Alpha、像素格式、mip 与 sRGB。

材质参数相同不能证明外观相同；纹理的绘制内容、父分支、遮罩与目标 UV 仍可能不同。跨 UV donor 需要投影或烘焙，而不是直接换整套纹理。

## 新材质路线

先证明原生对照或私有子实例无覆盖可用，再增加一个明显参数/纹理，单槽通过后扩大。无覆盖就灰格时停止，不继续堆所有槽。

UModel 保存后等长替换路径不证明 Package 身份、导入表和父类型正确。优先支持的结构化修改、UE 作者资源或经过格式分析的专用实现。

原生效果已经有时间驱动时可引用它；不为复用效果将 donor 的父材质和全部依赖一并覆盖。

## 纹理载荷

同格式替换应保持尺寸、像素格式、mip、载荷结构、影响压缩的 Alpha 与 sRGB 用途。只看 PNG 的 RGB 相同不足。

需要改变合同则重新 Cook 并建立相应验证。某资产要求 Alpha 全不透明，只属于该资产路线；不等于所有透明材质都禁用 Alpha。透明可能通过独立遮罩或层实现。

## 外观对照

保持同一角色阶段、场景时间、光照、相机和冲突状态。一个试包表达一个可判断假设；相关多文件可一起改，但不要混合无法分辨原因的独立变化。

白天正确时保留白天输入，先试夜间 ramp/overlay，色调正常后再试高光。多次 scalar 调整无效果时回到实际输入链。

跨阶数隔离必须有真实引用；仅改新文件名字不算隔离。修好正面不证明背面和相邻槽，按实际边界检查 UV 与通道。

输出记录已确认原因、仍是推断的原因、实际变更和对应实机结果。解析、Cook 与封包通过不能代替视觉结论。

## 运行时 VMD 故障分类

下表来自 2026-10-12 的国服原版案例，先验证是否符合当前条件，不直接推广固定骨数、参数偏移或组件名。

| 症状 | 证据与修复路线 |
|---|---|
| 重置新建 PoseableMesh 时崩溃 | 骨骼数组尚未初始化；先延迟创建、赋网格、完成注册，验证参考姿态；不调用无分配检查的 ResetBoneTransformByName 初始化 |
| 角色消失但脚本仍在采样 | 回读组件和骨骼缩放，检查 Lua 嵌套结构传参；未确认新网格被渲染前保留原角色 |
| 复制相同材质仍全黑 | 检查 LightingChannels、CustomDepth/Stencil 和 CustomPrimitiveData，复用实际原材质实例；不先重绘纹理 |
| 新口型代理导致灰脸或局部破面 | 对照原外观与通用 SkeletalMesh Morph 代理；案例改回正常的 Poseable 表示，以有界面部骨骼偏移近似表情，停止每帧重建脸部渲染代理 |
| 头发、耳饰或背饰错位 | 查独立骨架、原始局部姿态、真实插槽到骨骼关系与外观缩放，不把所有附属件当主骨架从属网格 |
| 黑色项圈在动作中转向另一侧 | 枚举静态网格和附属层级；案例 HeadNeckStaticMesh 仍跟原角色，需接入预览颈骨并保存/恢复其原可见性 |
| 浏览按钮无弹窗 | 核对 STA/COM 初始化、IFileOpenDialog 创建/显示结果及实际加载 DLL 修订号；不能用按钮响应代替文件选择器显示 |
| 另一个 VMD 无法播放 | 分别确认完整路径、中文/日文 Unicode 读取、CP932 骨名、骨骼/表情轨道类型和 FK/IK 语义；不要把纯表情或镜头文件当动作 |
| 启用音乐后设备名称/别名冲突 | 检查旧设备是否真正关闭及关闭返回码；案例跨创建线程关闭失败，改为同一进程内专用设备线程和唯一别名 |
| Ctrl+R 后角色残留或继续不显示 | 旧预览对象和隐藏状态未随 Lua 重载恢复；按同一进程会话及精确对象清单回收自己创建的表示，不能按类名删除所有 PoseableMesh |

菜单日志、原生文件/音频日志、关键变换回读、当前进程修订号和画面对照分别留证。重复播放卡住但未改资源时，还要按相机/互动技能检查调度锁，而不是继续改 Pak。

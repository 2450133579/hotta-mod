# 功能资源制作、封包和故障判断

## 作者链

从当前实际源码进入相关调用链，独立候选中完成：

准备作者工程 → 编译生成器及模块 → 生成蓝图/UMG/动画 → 蓝图编译 → Cook → 原生引用/必要格式处理 → 暂存 → 封包 → 回读 → 按授权安装与实机验证。

作者模块可提供原生类型签名或生成能力，但不因此成为必须随包安装的运行 DLL。占位类型、分析骨架、临时网格是否能移除，以实际引用为准。

原生修改保持既有名称、导入/导出身份、原事件调用及必要依赖。新函数和自制组件采用适合各自格式的序列化方式。

## 文件头与读取器

原生 unversioned 资源可能需要游戏专属头处理；自制显式版本 UE 资源使用相应标准读取方式。不要用一种读取器的拒绝结果判定另一种格式必坏。

外层 HT 包装不修复内部文件头。加载卡住需原始、重写和修复版本的最小对照及原字节分析，不仅凭停顿百分比推测 Tick 或相机逻辑已经执行。

## 界面和诊断

- 按键默认值必须采用工具真正支持的键名表示；序列化成功不证明输入有效。
- 某些运行时添加选项的 API 不会自动写入作者默认数据，必要时在 Widget 构造阶段初始化。
- 控件命名检查父类已有属性，避免名称冲突。
- Shipping 客户端中的调试输出可能被剔除；无日志不能直接证明分支未运行。
- 状态探针使用独立本地记录，限定本次所需字段，不覆盖官方保存。
- 控件值变化、目标接入和实际效果分别记录，不用面板可见证明执行链完整。

## 相机/外观故障

| 表现 | 核对方向 |
|---|---|
| 相机转了但前进仍沿旧方向 | 行走是否同步 ControlRotation |
| 转向被固定范围卡住 | 是否将静止环视限制用于整体移动 |
| 菜单中相机继续抢控制 | 光标、输入锁、原生接管与所有权 |
| 头发或饰品落到异常位置 | 独立骨架、附着参考和真实可见性恢复 |
| 动作中体型改变 | 是否绕过原生 AnimBP/缩放初始化 |
| 陷入家具或悬空 | 胶囊、Mesh、动作根和支撑面的空间关系 |
| 动作切相机从头播放 | 相机切换是否错误复用播放入口 |
| 全身爆体但源预览正常 | 最终压缩轨道与真实客户端 Skeleton |

## 打包和测试

保留必要 sidecar 和地图文件，核对实际覆盖清单及封包回读。相机与宿舍既要检查文件冲突，也要检查运行控制权冲突。

相机参数微调按受影响范围观察；播放或恢复逻辑修改增加相关取消、完成和离场测试。构建、挂载和安装成功分别记录，不把它们当成客户端行为验证。

报告本次具体对象、修改、实际执行的检查和仍缺证据的行为，不沿用私人历史版本的结论。

## UE4SS 调度与再次播放卡住

UE4SS v3.0.1 案例中，游戏动作回调持有 m_thread_actions_mutex，并调用需要 Lua 锁的接口；异步循环若此时持有 Lua 锁再排入游戏队列，会形成锁顺序互等。调度门保持关闭直到整段回调完成，不能在回调入口就把 scheduled 清为 false。按键和 Montage 请求先记录意图，再由同一更新入口消费，避免键盘线程直接操作游戏对象或再次争用队列锁。

保留重入回归样本：在 prepare 的引擎调用间模拟异步更新与停止按键，确认不会入队第二个动作，回调结束后才能重新调度。独立测试通过后仍需实机连续播放；不要从函数名就假设每个 ProcessEvent 都来自同一操作系统线程。

## Windows 文件选择与 DLL 修订

IFileOpenDialog 在具有消息循环的 STA 线程创建和显示，记录 COM、创建、显示及选择/取消结果。中文/日文外部路径用 Unicode API，VMD 内部名称另按 CP932；规范化斜杠、首尾空白和粘贴的双引号。旧 DLL 被菜单线程保持加载时，只复制新 Lua 不足以更新浏览器，需记录 DLL 修订号并采用独立文件名或退出游戏后替换。

按键模拟返回成功也不能证明框架重载；检查 runtime_menu_ready 的真实修订号。用户已授权的操作继续推进，必要的人机交接与技能未提供能力的情况如实说明，不制造额外确认流程。

## 音频资源的线程所有权

MCI 设备应由其创建线程操作和关闭。案例中游戏回调跨线程关闭得到错误 303，旧设备未释放又出现名称/别名冲突 265；不能忽略关闭结果后把句柄直接置零。把打开、状态、播放、暂停、音量和关闭统一发往 Mod 进程内的设备拥有线程，生成唯一别名并记录关闭结果。该线程不调用 Lua、不触碰游戏对象，也不是独立后台转换程序。

外部请求用完成事件传递结果，等待有界；请求在调用方超时后仍可能被设备线程持有，使用明确引用计数/生命周期避免悬空指针。测试不同调用线程、多次重开、暂停保持、恢复、循环与关闭；只在一个线程的独立样例中成功，无法覆盖客户端的创建者线程问题。

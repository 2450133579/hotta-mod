# 贴图、材质和局部覆盖

## 先确认谁渲染目标区域

从真实面到材质槽、MIC、父对象类型、静态开关、纹理参数和运行时覆盖逐层追踪。资源存在不等于被当前模型引用。

材质效果在某部位中断时，先检查相邻面是否属于另一个槽。不能靠重画当前槽的贴图覆盖另一个槽的面。

## 遮罩与图层

从实际选区生成 UV 线框、分槽色块或遮罩，说明对象、UV 通道、尺寸和上下方向。读取原 PSD 图层或 Alpha 通道，不从截图颜色反推精确像素。

预览分辨率和原图分辨率分别确认。重叠 UV 可能导致改一处影响多处；用户标记色只定义允许编辑范围，不是纹理内容。输出独立工作图层或新图，保留原稿与排除区域。

灰模区分真实装甲和画在同一曲面上的装甲。后者直接删面会挖掉身体，需按目标处理局部形状和相关纹理通道。

## 延续丝袜与织纹

从同材质完好区域采样，排除标志、缝线、装甲边和异常阴影。按需要分离低频明暗和高频织纹，保持方向及纹素密度，避免周期复制暗斑。

遮罩边界作适量颜色/梯度融合，保留纹理对比度。跨 UV 接缝通过对应三维边检查两侧，留出 mip 边缘扩展但不污染邻岛。

旧装甲和凹槽可能同时存在于颜色、法线、M/ID、LightMap 或 Alpha。先查每个通道的真实用途再改，不用统一灰色清空所有辅助图。参数拼写以真实资源为准。

## 格式和材质

记录尺寸、像素格式、mip 数、Alpha、压缩和 sRGB 语义。同格式载荷替换必须全部匹配；改变这些条件时选重新 Cook 或新的验证路线。

自制 UE 材质能 Cook，不表示客户端有对应 shader map。出现默认材质或 shader map 错误时先修运行链，优先使用已证明的原生父材质与私有子实例。

新 MIC 路线从无贴图覆盖的对照开始，再加明显参数和单槽测试。路线不变的普通改色不重复完整阶梯。

## 隔离与肤色

仅影响一个角色或阶数时，确认使用者实际引用私有 Mesh/MIC/贴图。复制文件而不改引用不能隔离；覆盖仍被共享的原路径会影响其他使用者。

不同 UV 的 donor 不能直接整套移植。用投影、烘焙或保留目标纹理的颜色调整实现所需外观。

头身 diffuse 的线性空间比较可作为调色起点，但阴影、材质分支和高光仍需同场景观察。保留已接受的模型基线，不为肤色问题重做无关骨架。

## 昼夜

真正昼夜变化依赖游戏时间驱动。静态烘焙只生成固定外观。白天已经正常时先保留白天与共享底色，单独检查夜间 ramp、overlay 或 mask，再处理需要的高光。局部路线通过不代表全部材质槽自动支持。

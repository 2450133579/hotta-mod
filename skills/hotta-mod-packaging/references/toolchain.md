# 工具配置与复用边界

## 首次接手登记

在接手者自己的私有配置中登记以下角色，不将真实路径或连接信息写回分享包：

| 配置角色 | 内容 |
|---|---|
| 作者工作区 | 可编辑源码、模型、贴图与生成配置 |
| 官方资源来源 | 当前客户端基础包、补丁及版本 |
| 活动覆盖 | 实际启用的 Mod 与挂载优先级 |
| 引擎与编译器 | 适配 UE4.26 的引擎、C++ 工具链及作者工程 |
| 资源工具 | FModel/UModel、repak、结构解析器和对应映射/解压依赖 |
| DCC 环境 | Blender、导入导出插件、可选 Lab MCP |
| 验证与输出 | 独立候选、暂存、报告和包输出 |
| 安装目标 | 游戏资源位置、活动 Mod 目录、链接关系及备份位置 |

源资源只读；生成文件与作者文件分开。仅按所需对象提取，不整库复制。

## 工具职责

- Everything 定位文件名；rg 查已定位目录的内容。索引不命中时先检查索引范围，不能直接认定文件不存在。
- FModel 便于浏览和引用发现；索引不可靠时换已适配的提取路线。
- repak 用于 Pak 清单和提取，不证明资源内容正确。
- UModel 的 dump/save/export 分别用于对象分析、分析副本和模型/纹理导出。save 不等于资源可任意重定位。
- PackageExportDump、SaveDecodedPackage 等是环境提供的特定工具。根据实际参数说明调用，不混用不同版本的签名。
- UAssetGUI/UAssetAPI 仅用于已支持的完整资源格式。
- Blender 处理作者模型。WeightBrush 从已保存模型生成离线预览，不能覆盖原生 AnimBP、IK、布料或 LOD。
- Photoshop 用于图层、通道和遮罩；Texconv 处理格式和 mip。
- UE4.26.2 是本工作流已使用的作者基线。对不同客户端先核对兼容性，不承诺任意版本通用。
- UnrealPak 与 HT 参与特定封包路线。HT 包装不修复 uasset 内部序列化错误。
- Python、PowerShell、.NET 和 C++ 工具链用于已有生成器和检查器。本包不提供这些执行实现。

## 环境适配

检查当前可用接口，不将专用检查命令当成所有 MCP 插件的标准能力。新的 Blender/导出器组合先用小样本验证。

文本明确使用 UTF-8；中文脚本需考虑执行宿主的编码规则。工具路径使用配置或显式参数，不依赖原作者的盘符、用户名、全局 PATH 或远程别名。

取得资源所需的访问配置独立保管，日志和报告不回显内容。分享文档只说明所需能力。

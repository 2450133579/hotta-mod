# 原版幻塔 Mod 制作总入口

这是脱敏的工作流文档版。工具与脚本由执行环境提供；先确认实际能力和当前客户端，不假定任何私人目录、既有安装或历史通过状态。

知识来源为用户提供的《幻塔原版Mod制作工具与流程.md》（标注 2026-10-05）、配套四个技能及 2026-10-12 的国服 PC 原版运行时 VMD 制作复盘。它们提供制作知识，不构成安装、修改客户端或启动游戏的独立授权。UE4.26.2 和 Blender 5.1.2 是制作基线；使用版本仍按执行环境与当前客户端确认，不作为所有客户端的强制要求。

首次准备环境或询问需要哪些软件时，先读 [入门工具与缺失依赖](references/getting-started-tools.md)。先确认区服、客户端版本、Mod 类型和可用工具，再做一个小样本；无需一次安装全部工具。当前技能只包含指导文档，不包含 HT 包装器、解码器、作者工程或可执行检查脚本。

## 先确定对象

确认用户要改的功能、客户端版本、使用者、实际 Mesh/Skeleton、外观阶段和覆盖资源。UI 名称、配置行、模型编号不能混用。官方基线与实际活动 Mod 分别识别。

保留当前可用版本与作者原件，在独立候选中工作。仅执行本次授权范围；文档任务不启动引擎、关闭游戏或安装包。

## 按变化选路线

| 变化 | 工作流 |
|---|---|
| 已有可用路线的重新封包、贴图或材质实例内容修改 | 核对输入和引用、暂存清单、封包回读、相关客户端结果 |
| 几何、权重、材质分区、UV、顶点色或绑定变化 | 模型检查、受影响的原生动作预览、完整重新 Cook、成品结构检查 |
| 不熟悉的 cooked 格式、资源重定位、新父材质/参数绑定 | 先做资源路线诊断，再以最小客户端样本证明 |
| 自定义动画导入、重定向、重新 Cook 或轨道映射修改 | 独立客户端骨架合同、原始/压缩双映射检查、最终 cooked 回放 |
| 游戏内浏览外部 VMD、叠加表情或同步本机音乐 | 已适配加载器、进程内解析和重定向、共享时间与恢复；不能仅靠资源 Pak 获得外部文件读取能力 |
| 相机、UI 或交互恢复 | 相关生成/编译及运行恢复检查，不展开无关模型审计 |

新材质路线由资源类别、制作方式、包路径策略、父对象路径/类型和参数绑定方法共同确定；其中一项改变就重新判断旧验证是否仍适用。

- [脚部与高跟鞋](references/footwear-retarget.md)：HS2 动作导入及足部修正必读。

## 关键约束

- 来源 PSK、图片和解析 JSON 是作者输入，不能冒充 cooked 文件。
- 保留源作者权重、面角 UV、自定义法线及手工选区，修改在副本进行。
- 新权重从本次最终保存的模型导出预览；网页草稿不等于作者源已保存。
- 动画以实际客户端消费的 Skeleton 为依据；名称一致不代表顺序和绑定一致。
- 一次诊断保持一个可判断的假设；同一假设允许涉及必要的多个文件。
- Cook、Pak 回读、动画绑定、实机运行和视觉接受分别记录。
- 只扩大受影响范围的检查，不把案例骨数、字节尺寸、固定视图数或全量动作列表变成通用门槛。

## 交付

说明修改目的、使用的基线、实际变更、对应客户端结果、已知问题和回退方式。资源路线提供 Pak/Sig 与封包回读；运行时路线提供 DLL/Lua、匹配依赖、文件清单及安装说明。增加本分支必要的模型、动画或材质证据即可；未执行的检查写明未执行。

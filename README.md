# hotta-mod
## Hotta Mod skills

This repository contains five focused Codex skills for the original Hotta PC client, UE4.26 assets, and related mod workflows. Each skill includes its `SKILL.md`, agent metadata, and reference documents.

| Skill | Focus |
| --- | --- |
| `hotta-mod-packaging` | Mod production entry point: asset replacement, Pak mods, runtime mods, and tool setup. |
| `hotta-camera-dorm-mod` | First-person camera, dorm interactions, and runtime motion preview. |
| `hotta-clothing-transplant` | Clothing and accessory transplantation, animation fit, and repair workflow. |
| `hotta-cooked-asset-routing` | UE4.26 cooked asset diagnosis, editing, and recook routes. |
| `hotta-blender-inspection` | Blender inspection of meshes, materials, UVs, weights, normals, and seams. |

## Layout

Skill directories are under `skills/`. Copy a complete skill directory to an agent's skills folder so its references and `agents/openai.yaml` metadata remain alongside `SKILL.md`.
